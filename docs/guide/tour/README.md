# A Tour of Luce Base

An introduction in ten chapters. Each one is built around programs you can copy into a
file and run, and each ends with a pointer to the next.

1. [Hello, Base](01-hello.md): installing, a first program, a first project
2. [Values](02-values.md): bindings, numbers, text and arrays
3. [Control flow](03-control-flow.md): `if`, loops, ranges and `match`
4. [Functions](04-functions.md): parameters, defaults, named arguments, several results
5. [Structs and enums](05-structs-and-enums.md): your own types and their methods
6. [Absence and failure](06-absence-and-failure.md): optionals, errors, `try` and `catch`
7. [Memory](07-memory.md): pointers, spans, `new` and `free`, allocators
8. [Modules and packages](08-modules-and-packages.md): files, imports and dependencies
9. [Calling C](09-calling-c.md): using C functions and C types
10. [Where next](10-where-next.md)

The Tour assumes you have programmed before, most likely in Python, and compares Base to
languages you may know where that helps. No knowledge of C is required, though it helps in
Chapters 7 and 9.
