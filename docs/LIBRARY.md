# The Luce Base standard library

Generated by `tools/library_reference.py` from `src/std/*.lucb`; the source is the reference. A module is reached with `import name` and used as `name.thing`, or `from name import thing` for its bare name (§16.6). Everything here is Base over `extern` declarations of the C library on arm64-macos.

## `memory`

### `Allocator` (interface)

What every allocator offers: blocks of bytes at an alignment, optionally resized in place, and given back (§12.4).

### `FixedBuffer` (struct: Allocator)

A bump allocator over a caller's bytes. Only the last block can be resized or released; everything goes away together when the buffer does.

- `static func over(buffer: u8[]) -> FixedBuffer`
- `mutating func allocate(size: usize, alignment: usize) -> u8[]?`
- `mutating func resize(block: u8[], size: usize) -> bool`
- `mutating func release(block: u8[])`

### `CAllocator` (struct: Allocator)

The C library's heap.

- `mutating func allocate(size: usize, alignment: usize) -> u8[]?`
- `mutating func resize(block: u8[], size: usize) -> bool`
- `mutating func release(block: u8[])`

### `Arena` (struct: Allocator)

Bump allocation over a parent allocator, released all at once by `reset` or `destroy` (§12.4, §24.3). One thread at a time.

- `static func over(parent: Allocator, capacity: usize) -> Arena!`
- `mutating func allocate(size: usize, alignment: usize) -> u8[]?`
- `mutating func resize(block: u8[], size: usize) -> bool`
- `mutating func release(block: u8[])`
- `func in_use() -> usize` — What has been handed out since the last reset, and what the arena holds in all.
- `func capacity() -> usize`
- `mutating func reset()` — Forget every allocation; the storage is reused from its start.
- `mutating func destroy()` — Give the storage back to the parent; the arena is empty afterwards.

### `PageAllocator` (struct: Allocator)

Whole pages from the host, each block its own mapping (§12.4). Safe from several threads.

- `mutating func allocate(size: usize, alignment: usize) -> u8[]?`
- `mutating func resize(block: u8[], size: usize) -> bool`
- `mutating func release(block: u8[])`

- `var diagnostic: bool` — `--profile diagnostic`: set by the startup shim before `startup` runs.

### `Site` (struct)

An allocation the diagnostic profile recorded (§19.4): the block, its size, and where.

- `var address: void*?`
- `var size: usize`
- `var function: str`
- `var line: u32`

- `func note_site(address: void*?, size: usize, function: str, line: u32)` — Called by the compiled program after each allocation under `--profile diagnostic`.

- `func allocation_sites() -> const Site[]` — The allocations recorded so far, the most recent 256 at most, oldest first.

- `let exhausted: ErrorCode = ErrorCode.package(1)`

- `let unset: ErrorCode = ErrorCode.package(2)`

- `var heap: Allocator`

- `func startup()` — Run by the startup shim before `main`, and by `thread.spawn` in a new thread.

- `func copy[T](target: T[], source: const T[], count: usize)`

- `func move[T](target: T[], source: const T[], count: usize)`

- `func set(target: u8[], value: u8)`

- `func read[T](address: const void*) -> T`

- `func write[T](address: void*, value: T)`

- `func grow(block: u8[], size: usize) -> u8[]!` — `block` with `size` bytes: in place when the current allocator can, else a new block with the old bytes copied and the old block released.

### `FormatSink` (struct: Writer)

The sink a formatted string offers a `Display` value (§14.4): it appends to the buffer the compiler is filling, and fails once that buffer is full, as `format` then does.

### `path` (struct)

The process's directories (§16.6): `from io import path`, then `path.user()`. Each is a `str` view of environment storage the system owns, or fresh storage from the current allocator where one has to be built.

- `static func user() -> str!` — The user's home directory: `$HOME`.
- `static func home() -> str!`
- `static func temp() -> str` — Where temporary files go: `$TMPDIR`, else `/tmp`.
- `static func config() -> str!` — Where configuration lives: `$XDG_CONFIG_HOME`, else `$HOME/.config`.

- `let io_path_failed: ErrorCode = ErrorCode.package(13)`

## `sync`

### `Mutex` (struct)

A lock whose waiters sleep: zero is unlocked, so `var lock: Mutex` is ready to use; one is locked; two is locked with someone asleep on it.

- `mutating func lock()`
- `mutating func unlock()`
- `mutating func try_lock() -> bool`

### `Condition` (struct)

A sequence number waiters watch; every signal advances it and wakes.

- `mutating func wait(mutex: Mutex*)`
- `mutating func signal()`
- `mutating func broadcast()`

### `Once` (struct)

Runs its function exactly once; later callers wait for the first to finish.

- `mutating func run(function: func() -> unit)`

### `Semaphore` (struct)

A counting semaphore whose waiters sleep.

- `mutating func acquire()`
- `mutating func release()`

## `paths`

File system paths as text, with `/` as the separator.

- `func is_absolute(path: str) -> bool`

- `func directory(path: str) -> str` — Everything up to the last separator, or `.` when there is none.

- `func base(path: str) -> str` — The last component.

- `func extension(path: str) -> str` — The extension with its dot, or the empty text.

- `func stem(path: str) -> str` — The last component without its extension.

- `func join(left: str, right: str) -> str!` — `left/right`, in the current allocator; an absolute `right` wins.

### `Address` (struct)

An IPv4 address and port, both in host order.

- `var ip: u32`
- `var port: u16`
- `static func loopback(port: u16) -> Address`
- `static func any(port: u16) -> Address`

### `Listener` (struct)

A bound TCP socket waiting for connections.

- `static func bind(address: Address) -> Listener!`
- `func address() -> Address` — The address the socket ended up with; a port of zero asked for any free one.
- `func accept() -> Connection!`
- `func close()`

### `Connection` (struct: Writer)

One TCP connection; it is a `Writer`.

- `var descriptor: i32` — The socket, for callers that poll or pass it on.
- `static func connect(address: Address) -> Connection!`
- `mutating func write(data: const u8[]) -> usize!` — Send every byte.
- `func receive(buffer: u8[]) -> usize!` — Receive what is available, up to the buffer; zero means the peer closed.
- `func close()`

### `Datagram` (struct)

A UDP socket.

- `static func bind(address: Address) -> Datagram!`
- `func address() -> Address`
- `func send_to(data: const u8[], address: Address) -> !`
- `func receive_from(buffer: u8[]) -> (usize, Address)!`
- `func close()`
